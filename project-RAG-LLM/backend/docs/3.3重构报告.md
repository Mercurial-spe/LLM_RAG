#### 3.1 支持多轮工具调用

修改 [graph.py](vscode-webview://14e5528qnmm2mcle0eportl11igk4if9qia5dnbq0gf87sqp2ir0/project-RAG-LLM/backend/app/agents/graph.py):

```python
# 当前: tool_exec → respond (固定)
graph.add_edge("tool_exec", "respond")

# 改为: tool_exec → orchestrator/respond (条件路由)
graph.add_conditional_edges(
    "tool_exec",
    _route_after_tool_exec,
    {
        "orchestrator": "orchestrator",  # 需要再次决策
        "respond": "respond",            # 直接回复
    }
)
```

 **决策逻辑** :

* 如果 `tool_results` 为空或失败 → 回到 `orchestrator` 重新决策
* 如果 `tool_results` 成功 → 直接 `respond`
