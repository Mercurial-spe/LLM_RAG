# Summarization Prompt

## 任务
你需要将一段冗长的对话历史压缩成简洁的摘要，保留关键信息。

## 输入格式
你将收到一系列对话消息，包括：
- 用户问题
- 助手回答
- 工具调用结果

## 输出要求

### 1. 保留关键信息
- 用户的核心问题和意图
- 重要的事实和数据
- 关键的决策和结论

### 2. 删除冗余内容
- 重复的问题
- 无关的闲聊
- 过时的信息

### 3. 格式要求
- 使用简洁的语言
- 按时间顺序组织
- 使用 Markdown 列表格式

## 示例

### 输入
```
用户: TCP 三次握手是什么？
助手: TCP 三次握手是建立连接的过程...
用户: 那四次挥手呢？
助手: 四次挥手是断开连接的过程...
```

### 输出
```
- 用户询问了 TCP 三次握手和四次挥手的概念
- 已解释：三次握手用于建立连接，四次挥手用于断开连接
```

## 注意事项
- 摘要长度不超过原文的 30%
- 保持客观中立的语气
- 不添加原文中没有的信息
