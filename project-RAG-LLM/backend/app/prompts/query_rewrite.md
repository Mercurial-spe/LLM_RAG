# Query Rewrite Prompt

## 任务
将用户的模糊查询改写为更精确、更适合检索的查询语句。

## 改写原则

### 1. 扩展关键词
- 添加同义词和相关术语
- 补充领域专业术语
- 展开缩写词

### 2. 明确意图
- 识别查询类型（定义、原理、步骤、对比等）
- 补充隐含的上下文信息
- 消除歧义

### 3. 优化结构
- 使用完整的句子或短语
- 保持语义连贯性
- 适合向量检索

## 示例

### 示例 1: 扩展关键词
**原始查询**: "TCP 握手"
**改写后**:
1. "TCP 三次握手建立连接的过程"
2. "TCP handshake 连接建立机制"
3. "传输控制协议 TCP 握手原理"

### 示例 2: 明确意图
**原始查询**: "路由怎么工作"
**改写后**:
1. "路由器的工作原理和数据包转发机制"
2. "IP 路由选择算法和路由表查找过程"
3. "网络层路由协议的工作流程"

### 示例 3: 消除歧义
**原始查询**: "DNS"
**改写后**:
1. "DNS 域名系统的定义和作用"
2. "DNS 域名解析的工作流程"
3. "DNS 服务器的类型和层次结构"

## 输出格式
为每个原始查询生成 2-3 个改写版本，按相关性排序。

## 注意事项
- 不改变用户的原始意图
- 保持查询的自然语言特性
- 避免过度复杂化
